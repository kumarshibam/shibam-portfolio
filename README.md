## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/kumarshibam/shibam-portfolio.git
```

**2. Open the project folder**

```bash
cd shibam-portfolio
```

**3. Open `index.html` in your browser.**
